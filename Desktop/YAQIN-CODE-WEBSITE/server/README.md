# راه‌اندازی سرور Yaqin Code

## پیش‌نیاز
Node.js (نسخه ۱۸ به بالا) باید روی سیستم نصب باشه.
بررسی کن: `node -v`

## مراحل نصب و اجرا

```bash
cd server
npm install
cp .env.example .env
```

فایل `.env` رو باز کن و مقدار `JWT_SECRET` رو به یک رشته‌ی تصادفی و طولانی تغییر بده
(مثلاً یک جمله‌ی درهم‌ریخته‌ی دلخواه). مقادیر تلگرام رو فعلاً خالی بذار (قدم بعدی).

```bash
npm start
```

اگه همه‌چیز درست باشه، این پیام رو می‌بینی:
```
✅ Yaqin Code server is running: http://localhost:3000
```

حالا مرورگر رو باز کن و برو به **http://localhost:3000**

## نکته مهم

⚠️ از این به بعد سایت رو **همیشه از طریق همین سرور** باز کن، نه با دابل‌کلیک
روی `index.html`. چون صفحه‌ی لاگین و دروس به آدرس‌های `/api/...` که فقط
وقتی سرور روشنه جواب می‌دن نیاز دارن.

## داده‌ی کاربران کجا ذخیره می‌شه؟

در فایل `server/data/users.json`. رمزها هرگز به‌صورت متن ساده ذخیره نمی‌شن،
همیشه با `bcrypt` هش می‌شن.

## دیپلوی روی سرور واقعی (بعداً)

وقتی خواستی سایت رو آنلاین کنی (مثلاً روی یک VPS)، همین پروژه با `pm2` یا
`systemd` قابل اجراست. اگه به اون مرحله رسیدیم جزئیاتش رو هم می‌سازیم.
