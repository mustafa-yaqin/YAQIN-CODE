# Yaqin Code — پلتفرم آموزش HTML/CSS/JS (دوزبانه)

## ✅ قدم ۱ (انجام‌شده): زیرساخت پروژه

- ساختار پوشه‌ها
- سیستم تم روشن/تاریک (`js/theme.js`) — ذخیره در `localStorage`
- سیستم دو زبانه فارسی/انگلیسی (`js/i18n.js` + `js/lang/fa.js` + `js/lang/en.js`)
- صفحه لندینگ (`index.html`) با هدر، هیرو، و یک **ادیتور کد زنده نمونه**
- توکن‌های طراحی در `css/variables.css`

## ساختار پوشه‌ها

```
w3fa/
├── index.html          صفحه اصلی (لندینگ)
├── css/
│   ├── variables.css   رنگ‌ها و فونت‌ها (توکن‌های طراحی)
│   ├── base.css        ریست و تایپوگرافی پایه
│   └── components.css  هدر، دکمه، ادیتور، فوتر، فرم
├── js/
│   ├── theme.js         سوییچ دارک/لایت
│   ├── i18n.js           سوییچ فارسی/انگلیسی
│   ├── mini-editor.js    ادیتور زنده نمونه در هیرو
│   └── lang/
│       ├── fa.js
│       └── en.js
├── lessons/              (قدم ۴ و ۵ — هنوز خالی)
└── server/                (قدم ۶ — بک‌اند تلگرام، هنوز خالی)
```

## نحوه اجرا (به‌روزشده — نیاز به سرور واقعی)

⚠️ چون الان لاگین/ثبت‌نام واقعی با بک‌اند و دیتابیس داریم، دیگه نمی‌شه فقط
`index.html` رو دابل‌کلیک کرد. راهنمای کامل راه‌اندازی این‌جاست:
👉 [`server/README.md`](./server/README.md)

خلاصه‌ش:
```bash
cd server
npm install
cp .env.example .env   # و JWT_SECRET رو عوض کن
npm start
```
بعد مرورگر رو باز کن: **http://localhost:3000**
